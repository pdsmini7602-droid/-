# 유진기업 하우징플랫폼 포털 사용법

## 폴더 구성
```
우리부서포털/
├─ index.html            포털 본체 (더블클릭하면 브라우저에서 열림)
├─ files/                자료실에 올라가는 파일
│   ├─ customer-support-guide.pdf   (고객지원_안내서.pdf)
│   └─ product-service-intro.pdf    (제품서비스_소개서.pdf)
├─ 이전버전/             원본 보관본
├─ README.md             이 문서
└─ release-checklist.md  공개 전 점검 체크리스트
```
`index.html`과 `files` 폴더는 항상 같은 위치에 두어야 다운로드가 동작합니다.

## 화면 구성
- 상단 메뉴: 홈 · 제품 소개 · 착공·수주 · 자재 시황 · 견적 계산기 · FAQ · 자료실. 지금 보는 영역이 강조됩니다.
- 모바일(폭 820px 이하)에서는 ≡ 버튼으로 접히고, 항목을 누르면 자동으로 닫힙니다. 바깥을 누르거나 Esc를 눌러도 닫힙니다.
- 화면 모드: 오른쪽 위 버튼으로 다크/라이트를 전환합니다. 기본은 다크이며, 선택은 이 브라우저에만 저장됩니다.
- 맨 위로: 아래로 내리면 오른쪽 아래에 나타납니다.

## FAQ 검색
검색창에 키워드를 입력하거나 카테고리 버튼을 누르면 해당 FAQ만 보입니다. 두 조건은 함께 적용되며, 띄어쓰기로 여러 단어를 넣으면 모두 포함된 항목만 나옵니다. Esc 또는 '지우기'로 검색어를 지웁니다.

## 자료실 파일 추가
1. 파일명을 영문 소문자와 하이픈으로 정해 `files` 폴더에 넣습니다. (예: `price-list-2026.pdf`)
2. `index.html`에서 `const FILES = [` 부분을 찾아 한 줄을 추가합니다.
```js
{tag:"PDF", saveAs:"가격표_2026.pdf", desc:"설명", size:"약 120KB", href:"files/price-list-2026.pdf"},
```
- `href`는 `files/파일명` 상대 경로, `saveAs`는 내려받을 때 저장되는 한글 파일명입니다.
- 다운로드 버튼은 `download` 속성이 있어 PDF도 새 창 없이 바로 저장됩니다.

## 내용 수정
- 연락처: 하단 문구와 `SALES_EMAIL` 값이 아직 예시(`contact@example.com`, `02-0000-0000`)입니다. 실제 값으로 바꾸세요.
- FAQ: `FAQS` 배열에서 수정합니다.
- 계산기 단가·할인율은 샘플 값입니다.

## 개인정보
견적 계산기와 메일 작성창에 입력한 내용은 저장하거나 서버로 보내지 않습니다. 메일 보내기는 사용자의 메일 프로그램(mailto)을 여는 방식입니다.
